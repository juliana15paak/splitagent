# SplitAgent 🤖

> 🎓 Projeto desenvolvido no contexto do **Laboratório de Experimentação IBM Bob**, com foco na aplicação de tecnologias emergentes e Inteligência Artificial para solucionar desafios reais relacionados à gestão financeira empresarial.

O **SplitAgent** integra uma proposta de experimentação tecnológica, explorando o potencial da Inteligência Artificial e de arquiteturas multiagentes no desenvolvimento de soluções inteligentes para análise, simulação e apoio à tomada de decisões financeiras.
Este repositório contém o **Frontend do SplitAgent**, responsável pela interface de interação entre os usuários e os recursos disponibilizados pela plataforma.

Acesse aqui: [SplitAgent](https://splitagent.vercel.app/)

---

## 🎯 Objetivo Geral

Desenvolver uma plataforma inteligente capaz de simplificar a gestão financeira empresarial, automatizando análises e transformando dados em informações estratégicas.

O SplitAgent busca tornar processos financeiros mais acessíveis, organizados e eficientes, utilizando Inteligência Artificial para apoiar empresas na compreensão de sua situação financeira e na projeção de resultados futuros.

## 🚀 Funcionalidades
- **Visão Geral:** centralização das principais informações financeiras da empresa.
- **Fluxo de Caixa:** acompanhamento das entradas e saídas financeiras.
- **Importação de Planilhas:** envio de arquivos para processamento e análise dos dados.
- **Chat Inteligente:** interface de comunicação com os agentes de Inteligência Artificial.
- **Criação de Cenários:** simulação de diferentes possibilidades financeiras.
- **Histórico de Simulações:** consulta às simulações realizadas anteriormente.
---

## 🛠️ Tecnologias Utilizadas

- **React:** desenvolvimento da interface através de componentes reutilizáveis.
- **Vite:** ferramenta de desenvolvimento e build da aplicação.
- **JavaScript:** implementação da lógica e interatividade do frontend.
- **CSS:** estilização e construção de uma interface responsiva.
- **Vercel:** hospedagem, publicação e integração contínua do frontend.
- **PWA:** recursos de Progressive Web App, quando habilitados no projeto.
- **API REST:** comunicação e integração com os serviços do backend.

## ⚙️ Como Executar o Projeto

### Pré-requisitos

- Node.js instalado.
- npm instalado.
- Acesso ao backend do SplitAgent.

### 1. Clone o repositório

```bash
git clone URL_DO_REPOSITORIO
```

### 2. Acesse a pasta do projeto

```bash
cd splitagent-frontend
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Configure as variáveis de ambiente

Crie um arquivo `.env` na raiz do projeto:

```env
VITE_API_URL=http://localhost:8000
```

Altere o endereço conforme a configuração do backend.

### 5. Execute a aplicação

```bash
npm run dev
```

A aplicação estará disponível em:

```text
http://localhost:5173
```

### 6. Gere a versão de produção

```bash
npm run build
```

## 🌐 Deploy — Vercel

O frontend do SplitAgent está preparado para hospedagem na **Vercel**, permitindo disponibilizar a aplicação na web de maneira prática.

Configurações de build:

| Configuração | Valor |
|:---|:---|
| Framework Preset | Vite |
| Build Command | `npm run build` |
| Output Directory | `dist` |
| Install Command | `npm install` |

As variáveis de ambiente necessárias devem ser configuradas diretamente no painel da Vercel.
